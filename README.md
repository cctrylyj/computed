# 体积计算器 PWA

## 使用方法

### 1. 本地使用
直接用浏览器打开 `index.html` 即可使用。

### 2. 部署到网络（推荐）
上传所有文件到：
- Netlify Drop: https://app.netlify.com/drop
- GitHub Pages: https://github.com
- Vercel: https://vercel.com

### 3. 添加到手机主屏幕
1. 用浏览器打开部署后的链接
2. 点击浏览器菜单（⋮ 或 ⚙️）
3. 选择 "添加到主屏幕" 或 "安装应用"
4. 完成后会像原生 App 一样使用

## 文件说明

- `index.html` - 主页面
- `manifest.json` - PWA 配置文件
- `sw.js` - Service Worker（离线支持）
- `icon.svg` - 应用图标

## 功能

✅ 长宽高输入框
✅ cm/m 单位切换
✅ 实时计算体积
✅ 离线使用
✅ 添加到主屏幕
